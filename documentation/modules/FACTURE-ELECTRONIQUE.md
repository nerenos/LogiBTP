Référence lue à la demande (hors contexte par défaut). Les règles que le code doit respecter sont dans [CLAUDE.md](../../modules/facture-electronique/CLAUDE.md) ; une règle modifiée l'est là, l'inventaire ici. Plan (29 lots, terminé le 12/11/2026) : [facturation-electronique.md](../conception/plans/facturation-electronique.md) ; analyse : [ANALYSE-FACTURATION-ELECTRONIQUE.md](../conception/ANALYSE-FACTURATION-ELECTRONIQUE.md) ; décisions Q1 à Q24 : [facturation-electronique-questions.md](../conception/plans/facturation-electronique-questions.md).

## Dépendances
- JS `@logibtp/facture-electronique` → `@logibtp/socle` ; développement : `vite` (démonstration), `saxon-js` et `xslt3` 2.7.0 (licence Saxonica), `xmllint-wasm` 5.3.0 (outil et tests). .NET : `LogiBTP.FactureElectronique` → Socle, PdfPig 0.1.16 ; `LogiBTP.FactureElectronique.Web` → module, Socle.Web, `Microsoft.AspNetCore.App`, EF Core Npgsql. Jamais du cœur ni d'un autre module (ni Document, ni Édition, ni OAuth : jeton par `IFournisseurJeton` du socle).
- Utilisé par : cœur (`Btp/*Fe*.cs`, `Btp/*FactureBtp.cs`, `Btp/EreportingBtp.cs`, `client/src/app/facture-electronique/`, `client/src/app/documents/{envoi-fe,completude-fe}.js`, page `pages/facture-electronique.js`, `db/295` à `db/305`). Module Édition : option PDF/A-3 générique (lot 18) employée pour le Factur-X ; module Comptabilité : catégorie EN16931 et VATEX des taux (`094g`, lot 10) ; module OAuth : flux CLIENT d'un fournisseur GENERIQUE (lot 7).

## Cœur (spécialisation)
- Branchement (lot 11) : `Btp/FactureElectroniqueBtp.cs` (`SpecialisationFactureElectroniqueBtp` : activation `module_societe`, droits du nœud `facture_electronique`, GED, signaux de notification, statuts reçus) ; `db/295` (activation, droits, catégorie GED `facture_electronique`, signaux).
- Réception (lots 12 à 15) : `Btp/ReceptionFactureBtp.cs` (flux reçu → A_FACTURE / A_AVOIR / T_FACTURE_AVT en brouillon, fournisseur par SIREN puis SIRET ou fiche provisoire, lignes, TVA par catégorie EN16931, commande de BT-13, GED à l'étape RECEPTION au coffre, statuts 204 / 205 / 207 / 210 / 211, hors plateforme, paiement direct 224) ; `db/296` (`v_liste_fe_recues`), `db/297` (signal PAIEMENT_DIRECT) ; client `facture-electronique/depot-facture.js`.
- Annuaire (lot 20) : `Btp/AnnuaireFeBtp.cs` (fiche personne, vérification de nuit en option) ; `db/298` (`per_fe_*`).
- Émission (lots 21 à 24, 27) : `src/LogiBTP.Calcul/EmissionFeBtp.cs` ↔ `client/src/calcul/emission-fe.js` (nature B / S / M, cadre, déjà payée ; jeu `tests/emission-fe/01_emission.json`), `Btp/EmissionFeDonneesBtp.cs` + `Btp/EmissionFactureBtp.cs` (pièce → modèle EN16931 : factures, acomptes, avoirs, définitives, situations, pied BTP, sous-traitance S5, cotraitance S6, B2G ; jeu `tests/emission-fe/02_pieces.json`), `Btp/EnvoiFactureBtp.cs` (contrôle à la validation Q5, CII / UBL / Factur-X PDF/A-3, GED ENVOI au coffre, file, tâche `PassageEnvoiFe`) ; `db/299` (BT-3 par type, nature), `db/300` (`document_fe_emission`, option, colonne `statut_fe`), `db/303` (`mar_fe_role`, récapitulatif de cotraitance) ; client `documents/completude-fe.js`, `documents/envoi-fe.js`.
- Rejet, refus, litige (lot 25) : `Btp/RejetFactureBtp.cs` (avoir interne ARCHIVEONLY ou non déposé, nouvelle facture, suspension de relance) ; `db/301`.
- Encaissée (lot 26) : `src/LogiBTP.Calcul/EncaissementFeBtp.cs` ↔ `client/src/calcul/encaissement-fe.js` (jeu `tests/emission-fe/03_encaissement.json`), `Btp/StatutEncaisseeBtp.cs` (liste à valider, CDAR 212 par taux) ; `db/302` ; client `facture-electronique/encaissements-fe.js`.
- E-reporting (lot 28) : `Btp/EreportingBtp.cs` (ventes B2C et internationales, encaissements, périodes, découpage, correction, relance) ; `db/304` ; client `facture-electronique/ereporting-fe.js`.
- Archivage (lot 29, Q21) : `db/305` (règle de rétention de la GED de la catégorie `facture_electronique` : 10 ans, archivage à 2 ans, revue à la fin ; élément GED `EREPORTING` dans `f_ged_element_existe`) ; transmissions d'e-reporting rangées en GED de leur période (ENVOI, coffre) par `SpecialisationFactureElectroniqueBtp.RangerAsync`.

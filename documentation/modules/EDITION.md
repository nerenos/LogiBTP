# Module Édition – référence détaillée

Référence lue à la demande (hors contexte par défaut). Les règles que le code doit respecter sont dans [CLAUDE.md](../../modules/edition/CLAUDE.md) ; une règle modifiée l'est là, l'inventaire ici.

## Dépendances
- JS `@logibtp/edition` : `@logibtp/socle` (décimaux), `pdf-lib`, `@pdf-lib/fontkit`, `qrcode-generator` ; `esbuild` (construction du paquet serveur). Jamais du cœur ni d'un autre module.
- .NET `LogiBTP.Editions` : `Jint`, `LogiBTP.Socle`. Polices : `js/polices/` (Inter 4.1 statique, Libre Barcode 39 ; OFL), copiées dans la sortie du projet .NET (`polices/`).

## Structure
- `js/src/` : `unites.js` (mm, formats A3–A6, longueurs %, mm, reste), `polices.js` (`Polices` : mesure sans crénage ni ligature, chiffres tabulaires `tnum`, `fontkitEdition` : mise en forme rapide installée pour pdf-lib), `texte.js` (`mettreEnLignes` : coupure, justification, ellipse, réduction, retraits), `html.js` (libellés HTML de la liste blanche sans DOM, Q19), `formules.js` (langage des champs, Q8 à Q10), `charte.js` (`CHARTE_DEFAUT`, styles, couleurs, traits), `composition.js` (composants → boîtes), `pagination.js`, `rapport.js` (`editer` : bandes, modes, sous-rapports), `etiquettes.js` (planches), `rendu-svg.js` (aperçu), `rendu-pdf.js` (`produirePdf`), `pdfa.js` (option PDF/A-3 générique `pdf.pdfa` : XMP et schémas d'extension de l'appelant, OutputIntent sRGB, fichiers associés `/AF` et EmbeddedFiles, `/ID` déterministe), `profil-srgb.js` (profil ICC sRGB livré, Little CMS, licence MIT ; copie binaire `js/couleurs/sRGB-lcms-v2.icc`), `codes.js` (Code 39, QR), `images.js` (PNG / JPEG, refus du SVG), `modele.js` (format, contrôle, dépendances, cycles), `truetype.js` (polices intégrées conformes), `catalogue.js` (`CATALOGUE_FONCTIONS` documentées, `CONTEXTES`, `OPERATEURS`, `FORMATS_CHAMP` : aide de l'éditeur et guide ; test : chaque fonction de `FONCTIONS` y figure), `faces.js` (`FACES_EDITION`, `chargerPolices`), `base64.js`.
- `js/serveur/entree.js` : API globale `LogiBTPEdition` pour Jint (`initialiser`, `pages`, `pdf`, `pdfLot`, `verifierModele`, `dependances`, `lireImage`) ; paquet construit par `npm run construire --workspace modules/edition/js` → `dotnet/LogiBTP.Editions/moteur/moteur-edition.js` (généré, versionné, ressource embarquée).
- `dotnet/LogiBTP.Editions.Web` : `Donnees.cs` (`EditionDbContext` : `charte_edition`, `modele_edition`, `modele_edition_version`, `modele_edition_lien`, `modele_edition_defaut`), `AccesEdition` (Q18 : niveaux de la GED + profils), `SpecialisationEdition` (sources, `ElementAsync`, `DonneesAsync`, `SourceAnnexeAsync`, `Dictionnaire`, `RessourcesAsync`, `ApresImpressionAsync`, `PeutUtiliser`, `PeutParametrer`), `ServiceEdition` (modèles : contrôle par le moteur, dépendances `Dependances.Lire`, cycles refusés, impacts, copie, versions ; chartes ; défauts ; `Preparer` : modèle demandé > dernier imprimé > défaut du type > premier, fermeture des blocs et sous-rapports, charte, ressources ; `Pdf`), `Extensions.cs` (`AddModuleEdition<T>(Base, moteurs)`, préchauffage du moteur, `MapModuleEdition`).
- `db/090_edition_schema.sql` (rejouable) : tables ci-dessus, versions par déclencheur ; `db/091_edition_taches.sql` : file `edition_tache` (production du serveur).
- Production (Q15) : `ServiceEdition.Planifier` / `TraiterEnAttente` (prise exclusive `FOR UPDATE SKIP LOCKED`, trois essais), `ProductionEdition` (tâche de fond, toutes les sociétés, section `Edition:Production` : `Actif`, `Intervalle`, `Lot`), dépôt par `SpecialisationEdition.DeposerAsync`, double par `DerniereEditionAsync`.
- `dotnet/LogiBTP.Editions` : `MoteurEditionJs` (Jint : script, polices, `Pages`, `Pdf`, compression zlib .NET des flux via `__deflate`), `PoolMoteursEdition` (instances prêtées, Jint non réentrant).
- `tests/cas/*.json` (modèle, données ou `generer`, env) ; `tests/donnees/` ; `tests/resultats-js/` (généré par `npm run exporter-resultats --workspace modules/edition/js`, non versionné) ; aperçus HTML et PDF des essais dans `js/.essais/` (non versionné).

## Modèle (résumé ; guide complet et dictionnaire : [GUIDE-EDITIONS.md](../../documentation/GUIDE-EDITIONS.md), à tenir à jour avec le moteur)
- Présentations (Q7) : `presentations: [{ code, libelle, parametres, defaut_si }]` : demandée, sinon la première dont `defaut_si` est vrai, sinon la première ; paramètres appliqués avant ceux de la demande, code lisible par `Parametre("presentation")`.
- Bandes : `ENTETE_PAGE`, `PIED_PAGE`, `FOND_PAGE` (filigrane, zones absolues), `CORPS` (aussi `TITRE`, `RESUME`) ; `pages` TOUTES / PREMIERE / SUIVANTES / DERNIERE / SAUF_DERNIERE ; modes UNIQUE, REPETE (`collection`), GROUPE (`rupture`, `entete`, `pied`, `regrouper`) ; options `saut_avant`, `saut_apres`, `saut_par_groupe`, `entete_chaque_page` (groupe, `groupe.suite`), `garder_ensemble`, `garder_avec_suivant`, `bas_de_page`, `chaque_page` ; pages `PAIRES` / `IMPAIRES`. Page : `format`, `orientation`, `flexible`, `marges`, `miroir`, `nombre_pair`.
- Composants : `champ` (valeur, style, format, alignement, multiligne auto|une|sauts, lignes_max, ellipse, reduction_min, html, masquer_si_vide, rotation, cadre, fond, marges, hauteur), `pile`, `rangee` (largeurs %, mm, `*`, meme_hauteur), `tableau` (colonnes, gabarits par condition — aucune condition vraie : rangée simple des colonnes — cellules fusionnées `de`/`a`, surcharges, retrait, fond, bordures, masquer, garder_avec_suivant, lie_au_precedent ; entête répétée, `cumul` → report, `total: { libelle }` (ligne des sommes des colonnes cumulées), `remplir` ; un tableau inclus dans une pile ou un bloc de bas de page garde son entête et son trait de fin ; colonnes dynamiques `colonnes_source` : une ligne par cellule, police réduite puis ellipse), `repete`, `image` (ressource par code), `trait`, `espace`, `code39`, `qr`, `absolu`, `saut_page`, `bloc` (lié, paramètres), `sous_rapport` (trois niveaux).
- Formats des champs : `montant`, `monnaie`, `nombre:N`, `simple:N` (zéros inutiles retirés), `pourcent`, `date`, `zero_vide` (valeur nulle non imprimée : lignes des documents).
- Formules : texte brut, gabarit `{{chemin}}`, expression `=…` ; résolution : `ligne`/`element`, `groupe`, `parametres`, `page`, `bloc`, puis racine des données ; erreur = champ vide + alerte (Q8).
- Fonctions (noms sans accents ni casse, arguments séparés par `;`) : `Si`, `EstVide`, `PremierNonVide`, `Concat`, `Joindre`, `Majuscule`, `Minuscule`, `Gauche`, `Droite`, `Longueur`, `Remplacer`, `Texte`, `Contient`, `CommencePar`, `Dans`, `Choix` ; `Nombre`, `Montant`, `Monnaie`, `Pourcent` (forme la plus simple, deux décimales au plus : 30 %, 85,26 %), `Simple` (idem sans %), `Arrondi`, `ArrondiSup`, `ArrondiInf`, `Abs`, `Min`, `Max`, `EnLettres`, `EntierEnLettres` ; `Date` (court, long, mois, heure), `AjouterJours`, `Aujourdhui` ; `Somme`, `Compte`, `Moyenne` (collection ; champ) ; `Page`, `NbPages`, `Parametre` ; mise en forme : `Gras`, `Italique`, `Souligne`, `Barre`, `Taille`, `Couleur`, `Style`, `Retrait` (retrait suspendu), `Ligne` ; `CodeBarre39`. Opérateurs : `+ - * /`, `&` (concaténation), `= <> < > <= >=`, `ET`, `OU`, `NON`.
- Collections, ruptures et données des sous-rapports : chemin nu (`lignes`) ou formule ; sources annexes déclarées par `sources_annexes: [nom]` au niveau du rapport, fournies par le serveur sous `sources.<nom>` (`SpecialisationEdition.SourceAnnexeAsync`).

## Routes HTTP (préfixe `/api/editions`)
- `GET /sources`, `GET /sources/{source}/dictionnaire` ; `GET /modeles?cible=&source=&type=&genre=`, `GET|PUT|DELETE /modeles/{code}`, `POST /modeles/{code}/copie`, `GET /modeles/{code}/impacts`, `GET /modeles/{code}/versions`, `POST /verifier` ; `GET /chartes`, `PUT /chartes/{code}` ; `GET|PUT /defauts`.
- `POST /apercu` (`DemandeEdition` : source, id, modele, presentation, format, orientation, parametres) → modèle, modèles disponibles, données, charte, blocs, rapports, ressources ; `POST /pdf` ({ edition, imprimer }) → PDF du serveur (en-têtes `X-Edition-Pages`, `X-Edition-Alertes`), `imprimer` retient le modèle et la présentation sur l'élément (Q13) ; `POST /productions` ({ edition, motif }) et `GET /productions?source=&id=` (file du serveur), `GET /rangee?source=&id=` (dernière édition rangée : double) ; `GET /modeles/{code}/export` (paquet `logibtp-edition` : modèle, blocs et sous-rapports inclus, charte, images en base64), `POST /import` ({ paquet, conflits : LIER | REMPLACER | RENOMMER } : inclus d'abord, références renommées réécrites, charte créée si absente, image de l'application gardée sinon créée par `CreerRessourceAsync`). Écritures : `PeutParametrer` (administrateur).

## Textes et icônes (module Personnalisation, lot P3r)
- Textes `edition.*` du `fr.json` du module (`alertes`, `lieux`, `formules`, `charte`, `images`, `modele`, `codes`, `imprime` : Report, À reporter, Total par défaut, `catalogue` : catégories, fonctions, opérateurs, contextes et formats de l'aide) ; dans Jint, `serveur/entree.js` pose ce dictionnaire du programme intégré au paquet (les surcharges de l'installation ne valent que pour l'aperçu) ; `exporter-resultats` et les tests le posent aussi (`test/preparation.js`). Restent dans le code : couleurs de la charte par défaut (contenu des éditions, réglées par les chartes), noms des mois et nombres en lettres, métadonnées du PDF.

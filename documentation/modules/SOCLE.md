# Socle – référence détaillée

Référence lue à la demande (hors contexte par défaut). Les règles que le code doit respecter sont dans [CLAUDE.md](../../socle/CLAUDE.md) ; une règle modifiée l'est là, l'inventaire ici.

## Dépendances
- Dépend de : `decimal.js`, `immer` (JS) ; `Microsoft.AspNetCore.App` (Socle.Web seulement). Ne dépend d'aucun module ni du cœur.
- JS `@logibtp/socle` (workspace `socle/js`) : dépendance de tous les modules JS (sauf `import`) et de `client`.
- .NET : `LogiBTP.Socle` ← projets de calcul des modules (Documents, Metres, Bibliotheque, Listes, Fiches, Annuaire) et `src/LogiBTP.Calcul` ; `LogiBTP.Socle.Web` ← projets `*.Web` des modules et `src/LogiBTP.Api` ; `LogiBTP.Socle.Testing` ← tous les `*.Tests` et `tests/LogiBTP.Calcul.Tests`.

## Structure
- `js/package.json` : exports `.` → `src/calcul/index.js`, `./ui` → `src/ui/index.js`, `./ui/socle.css`, `./dictionnaire` → `src/dictionnaire/index.js`, `./testing` → `testing/index.js`.
- `js/src/dictionnaire/` (module Personnalisation, [analyse](../documentation/conception/ANALYSE-MODULE-PERSONNALISATION.md)) : `resolution.js` pur ↔ `dotnet/LogiBTP.Socle/Dictionnaire.cs` (jeu `tests/dictionnaire.json` : clés à points, `{{nom}}`, `$t(cle)`, pluriel `_zero` / `_un` (|n| < 2) / `_autre`, repli, `fusionner`) ; `index.js` : dictionnaire courant — `chargerDictionnaire({ secours, surManquante })` (fetch de `/personnalisation/fr.json` et `images/icones.json`), `initialiserDictionnaire` (tests, Jint), `texte(cle, valeurs, defaut)`, `texteHtml` (texte et valeurs échappés ; clés `_html` : balises gardées), `pluriel(cle, n, valeurs)`, `existe`, `langue()` (`_meta.langue`), `icone(nom)` / `iconeHtml(nom)` (catalogue `images/icones.json`), `image(fichier)` (adresse versionnée), `clesManquantes`, `messageErreur(code, message, valeurs)` (lot P2 : `erreurs.<CODE>` sinon le message reçu, aussi s'il manque une valeur ; appelé par `ErreurApi` de `api.js`, qui garde le `title` du serveur dans `titre`). Point d'entrée léger, sans `decimal.js` (chargé avant l'application).
- `js/personnalisation/` : couche du socle — `fr.json` (`commun.*`, `socle.*` : dialogues, grille, raccourcis, touches, éditeur, signature, thèmes), `theme.css` (variables `--fond`, `--surface`, `--texte`, `--accent`…, clair et sombre : plus dans `socle.css`), `images/icones.json`. Les tests du socle posent ce dictionnaire (`js/test/preparation.js`, `vitest.config.js`).
- `js/src/calcul/decimal.js` : `Dec` (decimal.js cloné, précision 34, ROUND_HALF_UP), `D`, `Dz`, `coef`, `S`, `arrondir`, `arr6`, `formatNombre`.
- `js/src/calcul/expression.js` : analyseur de formules sans `eval` (grammaire identique à `Expression.cs`), `ErreurCalcul`.
- `js/src/calcul/references.js` : `analyserReference` (variable `$$ $ @@ @` ou donnée `table[id].colonne`), `analyserCibleVariable`.
- `js/src/calcul/libelles.js` : `remplacerVariables`, `texteBrut`, `formaterValeur`, `echapperHtml` (seul échappeur : `echapper` de `ui` l'appelle).
- `js/src/calcul/accents.js` ↔ `dotnet/LogiBTP.Socle/SansAccent.cs` : table d'accents unique (`SPECIAUX`, `ACCENTUEES` / `BASES` = décomposition NFD des lettres latines, générée et vérifiée par NFD), `sansAccent(texte)` ↔ `SansAccent.Retirer` (table, marques retirées, minuscules ; sans `normalize` : C# en globalisation invariante, Jint), `normaliser(texte)` (recherche : table puis NFD, même résultat que les fonctions SQL `f_sans_accent`, `f_annuaire_normaliser`, `f_ged_normaliser`) ; jeu `tests/sans_accent.json`, `SansAccentTests` (jeu et tables identiques).
- `js/src/api.js` : `ErreurApi(statut, code, message, details)`, `appelApi(url, { methode, corps, entetes, keepalive, Erreur })` (JSON ou `FormData`) : fournisseurs des modules (erreur du module = classe dérivée) et client.

Les modules JS sans dépendance (Calendrier, Pointage, Exécution) gardent leurs propres calculs.

## API publique
- JS `@logibtp/socle` : `Dec, D, Dz, S, ZERO, UN, coef, arrondir, arr6, formatNombre, evaluerExpression(texte, resoudre), referencesDe, ErreurCalcul(code, message), analyserReference, analyserCibleVariable, remplacerVariables(html, resoudre) → { texte, inconnues }, texteBrut, formaterValeur, echapperHtml, aujourdhui, dateLocale, numeroJour, depuisNumero, ajouterJours, joursEntre, jourSemaine, joursDuMois, ajouterMois`.
- JS `@logibtp/socle/ui` : tout `arbre.js` (+ `CFG_LIGNES` `lig_id/lig_parent_id/lig_ordre`), `GrilleArbre, Magasin, ListeDeroulante, AssistantFormule, confirmer, alerter, saisir, ouvrirDialogue, ouvrirModale, lireNombre, formatNombre, formatLibre, formatDate, formatDateHeure, formatHeure, htmlSur, echapper, estHtml, decoderEntites, lirePreferences, ecrirePreferences, actionDe, combinaison, libelleRaccourci, configurerRaccourcis, editerLibelle, THEMES, appliquerTheme`.
- `Magasin(saisie, { recalculer, identifiants, limite = 100 })` : `abonner`, `modifier(recette, libelle)`, `annuler`, `retablir`, `charger`, `appliquerServeur`, `prochainId` ; recalcul après chaque modification.
- `GrilleArbre(conteneur, { cle, colonnes, lignes(), actions })` : colonnes `{ cle, titre, valeur, editable, editeur: 'nombre'|'liste'|'select'|'formule', options, suggestions, classeCellule, titreCellule, largeur (px) }` ; disposition des colonnes si `actions.colonnesModifiees([{ cle, largeur }])` est fourni (entête glissé : ordre ; bordure droite : largeur, double-clic : automatique ; tableau figé dès qu'une largeur est réglée, `dispositionColonnes()`) ; `editeur: 'select'` = `ListeDeroulante` strict, valeur lue par `resoudre()`.
- .NET `LogiBTP.Socle` : `ArrondiCalcul.Arrondir / Arr6 / Racine / FormatNombre` ; `Expression.Evaluer(texte, Func<string, decimal>)`, `Expression.References` ; `References.Analyser` → `ReferenceVariable(Portee, Nom)` | `ReferenceDonnee(Table, Id, Colonne)`, `References.AnalyserCible` ; `Libelles.EchapperHtml / FormaterValeur / Remplacer / TexteBrut` ; `ErreurCalcul(code, message)`, `MessageCalcul(LigId, Code, Message)` ; `JsonCalcul.Options` (snake_case, nombres lus en chaîne), `JsonCalcul.Cloner<T>` ; `AccesColonnes.Colonnes / Existe / Lire` (propriété PascalCase ↔ colonne snake_case, héritage inclus).
- Droits : `IDroits` (`Droits.cs`, implémenté par le module Droits ; absent = droits historiques de chaque module) : `PorteeAsync(u, nœud, action)` → SOI / SERVICE / TOUT ou null, `ProfilsAsync` → `ProfilDroits(Code, Libelle, Total)` ; extensions `AutoriseAsync`, `ExigerAsync` (403 `ACCES_REFUSE`), `ExigeDroit(nœud, action)` sur un groupe de routes.
- Sécurité web (`Securite.cs`, module Droits lot 4) : `OptionsSecurite.Lire(configuration)` (LOGIBTP_DEPLOIEMENT LOCAL | INTERNET, LOGIBTP_CORS_ORIGINES, LOGIBTP_PROXYS, LOGIBTP_ADRESSES_CONFIANCE ; `DeConfiance(ip)`), `AddSecurite` / `UseSecurite` (en tête du pipeline : en-têtes transmis par les proxys déclarés seulement, nosniff, Referrer-Policy, Permissions-Policy, `frame-ancestors 'self'` si aucune CSP, HSTS sur INTERNET en HTTPS ; CORS paramétré ; écriture sur /api d'une autre origine ou `Sec-Fetch-Site: cross-site` → 403 `ORIGINE_REFUSEE` ; limites de débit `LimiteDebit` : connexion et jeton 10/min par adresse, mot de passe oublié 5/h, borne 60/min par appareil, diffusion 5 connexions, PDF / export / lignes de liste 2 simultanés, sinon seau de 50 jetons à 10/s par session (Bearer : 5/s), adresses de confiance non limitées sur la connexion ; 429 `TROP_DE_REQUETES`). `Masquage.Texte` (`LogiBTP.Socle`) : mots de passe, jetons, JWT, cookies, valeurs PostgreSQL « Key (…)=(…) », valeurs chiffrées, courriels, téléphones, NIR. `.env` chiffré (`Configuration.cs`) : `AjouterFichierEnv(dossier, cleEnv:)` déchiffre les valeurs `env:v1:` (AES-256-GCM, clé = SHA-256 de la clé de construction), `Sensible(nom)`, `ChiffrerLignes`, `ChiffrerValeur` / `DechiffrerValeur`, `CheminEnv`.
- Modules facultatifs : `IModulesActifs.EstActifAsync(code)` (implémenté par l'application ; absent = tout actif) et `ExigeModule(code, libellé)` sur un groupe de routes → 409 `MODULE_INACTIF` (`Modules.cs`).
- .NET `LogiBTP.Socle.Web` : `ExceptionMetier(statut, code, message, details)` + fabriques `Introuvable` (404), `AccesRefuse` (403), `Conflit` (409), `Invalide` (422) ; `UseErreursMetier()` → JSON `{ status, code, title, details }`.
- `Utilisateur(Code, Profil, Groupe)` : `EstAdmin` (profil `ADMIN`), `Utilisateur.Depuis(http)` : utilisateur posé par l'authentification (`Utilisateur.Poser(http, u)`, session du module Authentification) ; sinon (tests, mode `EnTetes` de développement) en-têtes `X-Utilisateur` / `X-Profil` / `X-Groupe` (défauts `demo` / `ADMIN`).
- Sociétés : `OptionsSocietes` (section `Societes` : `Domaines`, `Principale` ← `ConnectionStrings:LogiBTP`, `LibellePrincipale`, `Liste`), `SocieteConfiguree`, `SocieteCourante(Code, Libelle, Connexion)` (`Principale` si Code null, injectée en scoped), `AddSocietes(configuration)`, `UseSocietes()` (sous-domaine de l'hôte ; inconnu → 404 `SOCIETE_INCONNUE` ; `www`, IP, domaine nu → base principale), `SousDomaine(hote, domaines)` ; hors requête (tâches de fond) : `OptionsSocietes.Societes()` (principale puis liste, connexion renseignée) et `services.CreerPorteeSociete(societe)` (portée dont la `SocieteCourante` est imposée par `PorteeSociete`).

- `Constantes` : `Js(fichier, nom)` (paires d'un `export const NOM = Object.freeze({ CLE: 'valeur' })`), `Cs(type)` (constantes chaînes d'une classe), `Ecarts(fichier, nom, type)` (parité d'un `codes.js` et d'un `Codes.cs` : `A_FAIRE` ↔ `AFaire`), `ListeJs(fichier, nom)` (valeurs d'un `Object.freeze([OBJET.CLE, …])`).

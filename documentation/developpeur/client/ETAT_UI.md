"# État & UI (Client)\n\n> **Stack état :** Immer (magasin immuable), signaux réactifs maison\n> **Composants UI :** Maison (pas de framework), basés sur `@logibtp/socle`\n\n---\n\n## 🏪 Magasin global (Immer Store)\n\n### Architecture\n\n```javascript\n// socle/js/src/etat.js (simplifié)\nimport { produce } from 'immer';\n\nclass Magasin {\n  constructor(etatInitial = {}) {\n    this.etat = etatInitial;\n    this.abonnes = new Set();\n  }\n  \n  // Lecture directe (pas de proxy pour la lecture)\n  get(path) { return path.split('.').reduce((o, k) => o?.[k], this.etat); }\n  \n  // Écriture via Immer (producteur)\n  produire(recette) {\n    this.etat = produce(this.etat, recette);\n    this.notifier();\n  }\n  \n  // Abonnement réactif\n  s'abonner(fn) { this.abonnes.add(fn); return () => this.abonnes.delete(fn); }\n  \n  notifier() { this.abonnes.forEach(fn => fn(this.etat)); }\n}\n\n// Instance singleton dans Application\nthis.magasin = new Magasin({\n  utilisateur: null,\n  societe: null,\n  profil: null,\n  modulesActifs: {},\n  notifications: [],\n  fenêtres: [],\n  preferences: {},\n  // ... état par domaine\n});\n```\n\n### Utilisation dans les (Lightweight)\n\nPour l'état local de composant (pas global) :\n\n```javascript\n// socle/js/src/signaux.js\nclass Signal {\n  constructor(valeur) { this._valeur = valeur; this.abonnes = new Set(); }\n  get valeur() { return this._valeur; }\n  set valeur(v) { this._valeur = v; this.abonnes.forEach(fn => fn(v)); }\n  s'abonner(fn) { this.abonnes.add(fn); return () => this.abonnes.delete(fn); }\n}\n\nclass Calculé {\n  constructor(fn, déps) { this.fn = fn; this.déps = déps; this.valeur = fn(); }\n  // Recalcul auto quand une dépendance change\n}\n```\n\n### Exemple : Panneau métré\n\n```javascript\n// client/src/app/panneaux-btp.js\nthis.surface = new Signal(0);\nthis.longueur = new Signal(0);\nthis.largeur = new Signal(0);\n\nthis.surfaceCalculée = new Calculé(() => this.longueur.valeur * this.largeur.valeur, [this.longueur, this.largeur]);\n\nthis.surfaceCalculée.s'abonner(v => {\n  this.mettreAJourLigne('surface', v);\n});\n```\n\n---\n\n## 🧩 Composants UI

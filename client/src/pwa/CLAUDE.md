# Application installable (PWA) – contexte

Saisie hors ligne des documents et fusion : `src/app/hors-ligne/CLAUDE.md`.

- Application installable et hors ligne (PWA, lot 2) : `public/manifest.webmanifest`, `personnalisation/images/icone.svg` (module Personnalisation) ; service worker `src/pwa/sw.js` complété à la construction par le plugin de `vite.config.js` (règles `src/pwa/regles.js` sans les `export`, testées par `test/pwa.test.js`, fichiers de l'application, version) → `dist/sw.js` ; enregistré par `src/pwa/enregistrement.js` dans le client construit seulement (`npm run apercu --workspace client` : construction + aperçu sur 4173 avec le proxy de l'API, configuration `client-pwa` de `.claude/launch.json`). Fichiers de l'application gardés (cache d'abord), navigation → `index.html` gardé ; lectures de l'API (GET et POST de lecture `LECTURES_POST`) réseau d'abord puis réponse gardée (cache `logibtp-donnees`, en-tête `X-LogiBTP-Hors-Ligne` = date de mise en cache) ; panne = erreur réseau, 502 à 504 ou 500 sans JSON ; écriture ou lecture jamais consultée hors ligne → 503 `HORS_LIGNE` ; données effacées à la déconnexion (`purgerDonnees`) et au changement de compte (`signalerCompte`). Démarrage sans API avec le service worker et une session gardée : application hors ligne (`#passerHorsLigne` : bandeau « ● Hors ligne », classe `hors-ligne` du corps, contrôle toutes les 15 s).

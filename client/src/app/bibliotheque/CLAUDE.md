# Bibliothèque dans le cœur (appel, glisser, envoi) – contexte

Règles reprises du CLAUDE.md racine (06/11/2026) ; le serveur correspondant est dans `src/LogiBTP.Api/Btp` (voir `src/CLAUDE.md`).

- Glisser-déposer bibliothèque → document (entre fenêtres, HTML5) : la liste de la bibliothèque rend ses lignes glissables (option `glisser` de `ListeDonnees`, types `application/x-logibtp-article|ouvrage`, données `{ id, code, bib, type, societe }`) ; la grille accepte le dépôt (`actions.depotExterne`) avec un badge indiquant l'intégration (avant / après au même niveau, comme composante, dans la tranche), puis `AppelBibliotheque.deposer` insère l'élément (`insererContenu(..., { position })`). Raccourcis de la grille dans `socle/js/src/ui/raccourcis.json` (Ctrl+flèches : ordre et niveau).
- Appel d'un élément par son code (colonne Code) : absent de la bibliothèque du document → élément de même code d'une autre bibliothèque (le seul : pris d'office ; plusieurs : liste de choix `choisir(code, { memeCode })`), sinon recherche (`AppelBibliotheque.appeler`).
- Bibliothèque : type ENSEMBLE (structure réutilisable) : composition enracinée sur une tranche (titre) portant des paramètres `$` (`variables-tranche.js`, aussi dans le détail d'un titre de devis) lus par les métrés et libellés de ses lignes (vendues, options, variantes) ; prix = totaux de la tranche (`calculerEnsemble` / `ElementsBibliotheque.CalculerOuvrage`, qui calcule un ensemble par sa méthode privée `CalculerEnsemble`, jeu `tests/cas/15_ensemble_tranche_parametree.json`). Liste des éléments : sélection multiple (Ctrl / Maj), glisser de plusieurs éléments (`AppelBibliotheque.deposer` les insère en une étape).
- Document → bibliothèque (`client/src/app/bibliotheque/envoi.js`, bouton « 📤 Vers la bibliothèque ») : élément → article, ouvrage → ouvrage, titre / section → ensemble ; lien par l'ID (`lig_art_id`, `lig_proprietes.element.id`) pour la mise à jour ; sinon doublons par code (même bibliothèque) ou libellé proposés au rattachement, ou création (code et bibliothèque au choix). Écritures par les fiches `element` (verrou, empreinte) ; composition extraite du sous-arbre (quantités absolues rendues relatives, `compositionDepuisContenu`) ; coefficients de la ligne imposés à l'élément ; PV fixe d'un ouvrage envoyé seulement avec l'option de la société (`pv_fixe_ouvrages_envoyes` de `parametre_bibliotheque`, onglet Prix de `/parametres/bibliotheque`, non par défaut).
